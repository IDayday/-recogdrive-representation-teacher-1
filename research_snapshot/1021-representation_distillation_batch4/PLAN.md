## 3. 模型与统一监督接口

设观测为x，学生接口为 `Hθ(x)=Pθ(VLMθ(x))`，冻结动作生成过程为 `D0(H,c,ξ)`；c为历史轨迹、自车状态等原有条件，ξ包含动作生成所用的完整随机流。θ仅代表最终确认允许训练的参数，不意味着所有上游参数都会训练。

主目标H是 **`action_head.feature_encoder` 的实际输出，包含干预后状态**。该投影虽然位于名为action_head的模块内，但需要与其后的动作生成网络单独定义冻结边界。参考实现的small分支为1536维输入的线性投影；输出维数、token、精度以首版资产及实际配置复核为准。

选择最终接口的理由：所有首版上游修复已完成，下游保持同一个Base动作生成过程，学生直接拟合能够产生获选轨迹的实际输入状态。较早层差异经过传播可能减小，因此既看接口误差，也看最终行为；不假定接口差异小就没有行为价值。

在接口、其他条件、完整随机流与执行模式一致时，冻结动作生成过程的数学输出相同。但近似拟合时，普通接口误差与轨迹误差的关注方向不同：局部可近似为 `L轨迹 ≈ δHᵀ JᵀJ δH`，而普通接口MSE对各坐标等权。联合监督是否更有效，需要实际比较。

动作生成网络的参数冻结，**梯度仍可穿过它回传给接口及可训练上游**。不得把学生动作生成前向整体置于no_grad，或沿用会detach的推理缓存作为可训练链路。冻结模块保持eval；优化器只包含明确允许更新的参数，并核查冻结参数未变化。

## 4. 教师接入与R2定义

候选定义以[首版清单](../1021-representation_repair_batch3/manifests/first42_v1.json)为准；当前清单SHA256为 `6ebc7bb74eabd7549fead47e040163bae086645ee693015d78ff9f186d5e3da8`。预期正式入口为第三批 `teachers/first42_v1/FROZEN.json`、`PACK.json`、`R2.jsonl`；实际可用性及哈希在接入时核验。

对每个场景i，定义：

```text
c*(i) = argmax_c mean_{j=0..4} PDMS(i,j,c)
B(i)  = mean_{j=0..4} PDMS(i,j,Base)
T(i)  = mean_{j=0..4} PDMS(i,j,c*(i))
Δ(i)  = T(i) - B(i)
```

- 使用未舍入分数；完全同分沿用首版固定规则，优先Base。不用显示精度或新增任意收益阈值删除真实提升；数值无效、未完成或无法复现的记录单列核验。
- 同一场景固定一个实际候选，保留其五次轨迹与对应接口。不能对某次较差输出临时回退Base，也不把五次轨迹平均成新的教师轨迹。
- 上游候选的接口预期不依赖动作采样噪声，逐场景核验五次一致性。R1不同噪声可能选到不同接口，不直接混为主训练标签；R3保留原诊断口径，不增加为第一版主教师。
- 获选轨迹与接口必须来自同一次实际执行。引用记录ID、候选ID、噪声、输入、轨迹／表征／评分哈希；不拼接不同分支，不直接平均不同隐藏状态，不人为放大修复残差。
- 原始输出与正式快照只读。缓存或补充导出放本任务目录，绑定来源，不覆盖第三批资产。

首版接口导出保存有效token及其位置／input_ids。现有动作头代码包含对整个token序列的均值及交叉注意力，因此**不能默认删除padding或重排token不会影响行为**。接入前核查实际序列长度、padding、掩码及其他条件，完成接口注入重放；如需补充完整上下文，仅重放已选定分支并验收轨迹和评分，不重新选教师或修改动作头语义。

## 5. 训练数据组织

### 5.1 入池规则

| 池 | 场景定义 | 监督目标 |
| :---: | :--- | :--- |
| I：提升池 | Δ(i)>0 | 选定R2教师接口与该候选五次实际轨迹，不设绝对质量门槛 |
| P：保持池 | Δ(i)=0且B(i)>90 | 原Base接口与配对噪声下的Base轨迹 |
| E：仅评价池 | Δ(i)=0且B(i)≤90 | 不参加训练、不设置GT回退；完整保留评价 |

Base在候选集合内，正常R2不应出现Δ<0；出现时作为身份／计算异常核查，不默默归入某池。I、P、E覆盖全部有效场景且互斥。保持条件是**场景五次均分**，因此个别噪声较低仍可能入P，单次情况另列报告。

原会话划分保持不变：第一版拟只在85,813探索场景中按上述规则抽取训练数据，17,475验证场景用于开发选择；具体清单接入时核对。验证教师已生成不等于可参与梯度训练。测试数据及测试教师不进入学生训练或超参选择。

### 5.2 防止学习量失衡

所有真实提升都保留训练资格，但不要求按自然频率采样。先统计I／P／E数量、Δ分布、原Base质量、失败模式、会话、接口修复范数和教师来源；不要因为I数量多就认定难例监督已足够。

在I内可进一步区分“至少一次Base<70的提升场景”和其余提升场景，用于采样及报告，不恢复<70准入门槛。候选采样设置包括自然比例和增加难例曝光的混合比例，**最终比例尚未确定**。先用少量配置比较，不把此前讨论的比例当已选最优。

按场景计权，五次噪声是同场景的多个行为目标，不算五个独立场景。训练可轮换噪声；若一次展开多个噪声，接口损失不应意外重复加权五倍。P轮换覆盖合格成功场景，避免长期只保持少数容易样本。

区分数据池采样权重与单样本内部损失权重，避免两处同时放大形成未记录的偏置。各组记录场景曝光次数、独立场景覆盖、噪声覆盖和实际批次组成。Base初始化时P的接口损失为零，因此不能简单推断其样本多就必然产生更大的初始梯度；训练后的保持压力与冲突需实际测量。

第一版沿用教师输入预处理。不得改变图像／观测后继续使用不对应的缓存接口标签。

## 6. 损失与主比较

主框架为 `L = λH L接口 + λτ L轨迹`；样本池权重另外记录。第一版无动作头中间状态／去噪响应损失。

- **接口损失**：同token、同坐标的实际接口MSE，按token数和维度取均值；先采用清楚可复核的定义。余弦、子空间加权等不自动叠加。仅池化向量不替代完整接口。
- **轨迹损失**：学生以配对完整噪声通过冻结原生动作生成链，拟合该次教师最终轨迹。坐标单位、时域、位置与航向权重、航向周期处理，在训练前独立冻结；不把GT或不可微PDMS假装成反传标签。
- **保持损失**：P使用同一形式，目标改为Base。I中低绝对分但有提升的教师继续参与；其残留问题由真实PDMS评价揭示，不以GT替换。
- **诊断**：同时看绝对接口误差、修复残差相对误差、轨迹误差、真实PDMS。`(Hs−H0)−(Ht−H0)`与`Hs−Ht`完全相同，不能把此重写宣称为更强监督。相对误差在教师残差近零时单独处理。

权重尚未确定。可在训练侧的小样本上估计两项对统一接口的梯度量级，作为尺度校准，再比较偏接口／平衡／偏轨迹的少量固定权重；例如目标梯度比0.25、1、4只是待试配置。不得仅看原始loss数值大小定权，也不未经验证使用逐批动态加权。

| 组别 | 用途 | 比较要求 |
| :--- | :--- | :--- |
| B0：原RL Base | 配对行为基线 | 同场景、同噪声、同评分 |
| H：仅接口 | 检验实际接口教师是否可学、可转为行为 | λτ=0 |
| T：仅轨迹 | 判断额外接口监督的独特价值 | λH=0；是必要对照，不代替主方案 |
| HT：接口＋轨迹 | 主方案候选 | 少量权重配置，验证后确定 |

H／T／HT应使用相同教师、数据池、采样、学生初始化及可训练范围；匹配优化步数／场景曝光，并报告真实训练成本。避免因某组额外看到更多样本或噪声而把收益误判为表征蒸馏效果。不同组允许在相同开发预算内调参，不强迫使用不适配的学习率来制造差异。

## 7. 随机性与复现

RL actor沿用epoch24／global_step8325，checkpoint SHA256：

`23fb949b10387efeff87e093703d5faf41b61b9e5ead16d4076661e3c7c08a20`

教师执行身份以第三批记录为准：planner FP32、eval、autocast关闭、DDIM eta=1、时间步 `[80,60,40,20,0]`；训练接入时现场复核。不能把训练入口默认采样器当作原生教师采样器。

```python
seed = int(sha256(f"{token}|20261008|{j}".encode("utf-8")).hexdigest()[:8], 16)
# S0～S4对应j=0～4；S0不是全局整数0。
```

## 9. 评价与结论标准

- **主指标**：相对相同输入／噪声的Base，学生真实PDMS及增益。完整navtrain（训练＋验证103,288）必须报告，同时分开训练／验证，不能把混合总体成绩称为独立泛化。
- **额外表征监督价值**：HT对T的增益及会话级置信区间，使用相同教师轨迹与匹配训练预算。H解释仅接口监督的可学习性。
- **修复与保留**：I／P／E及原Base质量层分别报告；包括未参加训练的E，不能从总体分母删除。统计>90降至≤90／<70、新增与解除碰撞、出界、零分、TTC等，不用额外安全门槛筛教师。
- **跨场景／噪声**：保留会话划分，分别报告原五噪声拟合和新噪声表现；重复采样不是独立场景。会话级bootstrap，训练重复另报，不混作同一种不确定性。
- **教师收益吸收**：仅在相同场景和噪声口径下比较学生与固定R2教师的增益，可报告吸收比例；教师Oracle不是学生理论上界，比例分母近零时不解释。新噪声若无教师实算，仅报告学生对Base，不移用旧Oracle分母。
- **过程诊断**：接口／轨迹误差下降却PDMS不升，应定位行为敏感方向、质量门槛和分布偏移；训练可拟合但验证无增益，区分可学习性与泛化。一次失败不能直接证明表征路线无潜力。

本轮重点打通蒸馏与验证联合监督增量。NAVSIM既有PDMS评价不自动代表已做闭环验证；闭环实验需单独确定环境与协议。

## 10. 备选：逐层表征对齐

只保留方案，不作为首版主实验。若启用，应对齐**同一获选教师实际前向路径**的多个上游层及最终接口；修复之前的层可能仍完全等于Base，不能统称为修复后的正确表征。独立把每层推到总体成功分布，不等于得到输入条件一致、能够产生正确行为的整条路径。

潜在收益是给较早层更直接的监督，并约束下游漂移；潜在代价是更强地限定学生的实现路径，使多个样本／修复位置的约束相互牵制。现有统一接口资产不等于拥有修复后逐层轨迹，旧Base前缀缓存不能冒充教师修复后的下游状态。

需要时重放已选分支补采，并验收最终轨迹／接口一致。可比较少数层与逐层监督，各层按token／维度规范化并控制总权重，不能仅因加层数而无意放大总损失。仍不将动作头中间状态加入此备选。
