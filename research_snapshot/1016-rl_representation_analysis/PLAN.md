## 核心观察问题

- 差异从动作编码、条件融合到DiT各层如何变化，集中在哪些动作token和去噪时刻？
- 相同失败模式中是否存在共同结构；出界、碰撞、进度不足等是否对应不同结构？
- 全维差异较弱时，低维主子空间、残差空间或配对差分空间能否揭示稳定分布差异？
- 探索集发现的结构能否在留出场景、独立采集会话和另一组配对噪声中复现？

首轮允许只得出描述性差异。观察到分离不直接等于失败原因或可修复性；这些更强结论需要后续实验。

## 轨迹与表征的对应协议

### 质量标签（已冻结）

原始S0失败池使用PDMS<70；原始GT及加噪初始化来源仅记录原始评分，不按70／90提前筛除。以下质量标签在完整去噪、重新评分后，进入成功／失败表征分析前应用。按未四舍五入的原始评分判定，明确记录评分尺度：

| 类别 | 百分制PDMS | 0至1评分 | 用途 |
| :---: | :---: | :---: | :--- |
| 失败 | < 70 | < 0.7 | 原始失败池及最终失败表征 |
| 去噪后高质量成功 | > 90 | > 0.9 | 最终高质量候选及成功表征 |
| 中间质量 | 70 ≤ PDMS ≤ 90 | 0.7 ≤ score ≤ 0.9 | 保留并作连续质量分析，不并入成功／失败两端 |

**恰好70分或90分均属于中间质量。** 本计划后文的“成功表征”指上述高质量成功。无效输出、评分异常或缺失单独统计，不直接记作低分失败。安全分项用于失败模式分析，不另行改变这次按PDMS划定的质量标签。

### 原始配对

对新基线筛出的 **PDMS < 70** 的失败场景，保存同一观测下的模型失败输出和真实GT。GT使用与模型相同的坐标、预测时域、采样间隔和评分流程，原始GT的PDMS仅作诊断记录，**不作为原始配对的入选门槛**。即使原始GT不高于90分，也保留该配对进入加噪、完整去噪和最终重评分。记录安全分项，必要时记录道路／障碍余量，避免将擦边高分直接解释为稳健正确参考。

真实GT与metric cache中的PDM参照轨迹分开标识。只有GT缺失、形状／坐标不合法等数据问题才单独记录为无法构造原始配对；不因原始GT分数低而排除。GT来源不预设成功标签，最终候选按重新评分后的<70／>90门槛分类，全部结果保留。

### 配对加噪与完整去噪

1. 固定场景观测、自车状态、历史条件、RL权重与推理模式；同场景复用经过核验的条件特征。
2. 对原始失败轨迹与GT使用相同归一化、相同扩散时刻、相同初始噪声加噪；随机去噪时还应控制后续各步噪声的配对关系。
3. 从与加噪时刻匹配的位置继续去噪至最终轨迹，保存实际执行路径上指定层、动作token和去噪步的表征。
4. 对最终物理坐标轨迹重新进行官方评分，以最终质量标记其生成过程中的表征。

当前读到的共享源码中，`get_action`接受`init_actions`，但循环从完整时间表第一步开始。实现中间时刻续采时，必须在本任务代码内显式处理起始时刻、对应采样索引及后续时间表，不能把任意加噪轨迹直接交给原完整循环。此接口判断在复制或引用源码时再核实。

“固定种子”不等于关闭原有随机采样。基线和参考续采均明确记录实际`deterministic`、噪声、截断、精度等参数，避免不同入口默认值改变协议。

### 重新评分与样本保留

每个候选同时保存**轨迹来源**和**最终结果**：GT初始化可以最终失败，失败输出初始化也可以最终成功。两条都成功、两条都失败、结果反转和中间质量均完整保留，不只留下预期的成功／失败配对。

同场景、相同起始时刻和配对噪声下，最终形成质量差距的候选是主要比较对象；记录其占全部尝试的比例，避免把筛选后的覆盖率当全体覆盖率。自然推理与参考初始化续采分别统计，后者不计作Base自然性能提升。

最小追溯链为：

`场景与观测 → 轨迹来源及原始评分 → 加噪时刻和随机数 → 实际生成过程及表征 → 最终轨迹和重新评分`。

记录至少包含：场景token及采集会话、集合归属、模型／源码／配置指纹、特征指纹、原始轨迹、原始PDMS与分项、初始化来源、有效种子及采样编号、加噪时刻、去噪时间表、层／token／步索引、最终轨迹、最终评分、表征文件位置和运行身份。

## 主基线S0与随机数协议（已冻结）

本次RL全量自然推理主基线命名为 **S0**，沿用已有IL基线S0的种子映射：**根种子 `20261008`，采样编号 `j = 0`**。研究上不要求与旧工作使用同一组种子；沿用的理由是减少不必要的协议差异并保持命名一致，不因某组种子得分更好而选择它。本任务的RL模型、数据和运行记录仍独立保存。

**官方设置核查（2026-10-16）：** 检查官方仓库版本 `5831ee83c7a6a40bf6919715b96b0e9ba2b48335` 的2B／8B评测脚本、ReCogDrive评分入口及其公共／评测／agent配置，以及[训练评测说明](https://github.com/xiaomi-research/recogdrive/blob/5831ee83c7a6a40bf6919715b96b0e9ba2b48335/docs/Train_Eval.md)和[论文v2](https://arxiv.org/html/2506.08052v2)，未找到明确报告或绑定的轨迹推理种子。官方[训练配置](https://github.com/xiaomi-research/recogdrive/blob/5831ee83c7a6a40bf6919715b96b0e9ba2b48335/navsim/planning/script/config/training/default_training.yaml#L21)有 `seed: 0`，由训练入口调用；[评测入口](https://github.com/xiaomi-research/recogdrive/blob/5831ee83c7a6a40bf6919715b96b0e9ba2b48335/navsim/planning/script/run_pdm_score_recogdrive.py)不继承该训练配置，不能据此认定官方评测采用seed 0。因此本计划采用已可核实的旧S0映射；若实施前获得明确适用于该RL模型的官方推理种子协议，优先采用并在运行前同步修订记录。

每个场景实际使用的32位整数种子为：

```python
import hashlib
root_seed = 20261008
j = 0  # S0；以后若增加自然重采样，S1、S2分别对应j=1、2
seed = int(hashlib.sha256(f"{token}|{root_seed}|{j}".encode("utf-8")).hexdigest()[:8], 16)
```

例如，场景 `0002d40d9c7753d8` 的S0有效种子为 `1153522530`。**S0是一张按场景固定的采样种子表，不是整数0，也不是所有场景共用一个整数。** 映射来源为现有[种子协议](../1010-il_baseline/config/seed_protocol.json)及[实现](../1010-il_baseline/code/common.py)；只复用随机数约定，不引入旧实验数据或标签。

每场景在特征准备完成、轨迹forward之前设置 `random.seed`、`numpy.random.seed`、`torch.manual_seed` 与 `torch.cuda.manual_seed_all`。自然基线的哈希输入仅含上述token、根种子和采样编号，不加入模型、协议阶段、节点、rank、设备、分片、路径或处理顺序；实现时核查分片、批处理及恢复运行不会改变逐场景随机流。保存token到有效种子的映射，并通过重放验证；同一整数种子不自动保证不同模型／采样实现消耗相同噪声或产生相同轨迹。

GT／失败输出的配对加噪续采使用单独记录的随机数协议，不混用自然基线S0的名称。其映射在配对预实验前冻结，两分支共享相同的加噪噪声及应配对的后续随机量，保留噪声组编号、起始时刻和实际有效种子。

## 低维与分布分析

按相同层、动作token、去噪时刻和续采协议组织表征，先分别分析，避免把不同噪声水平混在一起形成平凡分离。探索／验证按采集会话分组；重复采样不能充当独立场景。

### 路线一 模型自然成功／失败输出的主子空间与残差（已完成）

**独立数据来源：完整navtrain自然S0输出（103,288场景，其中PDMS>90有90,153条、PDMS<70有2,288条，中间质量10,847条保留）。不使用GT初始化或配对续采候选充当路线一数据。已重放原S0并逐条精确核对103,288条已有轨迹，提取全部自然生成路径表征，完成本路线。**

1. 分别对最终成功和失败表征做SVD，取得相同维数的特征空间基`U_success`和`U_failure`。
2. 比较谱、子空间重合与分布差异。例如计算失败基在成功主子空间之外的部分：`R = (I - U_success U_success^T) U_failure`。
3. 对`R`再做SVD，按实际残差奇异值选取有效正交方向。记录残差能量；不将近零数值残差放大成稳定结构。
4. 将两类表征投影到**同一个**残差坐标系，比较均值、协方差、分布重叠与质量关联。不能把两类各自在不同坐标系中的图直接当作分离证据。

这是参考实现，不限制必须复刻旧算法。中心化与未中心化结果都要清楚定义；保留类间均值差异，不因分别中心化而无意消掉目标信号。

### 路线二 模型失败输出与对应GT的配对子空间与残差（已完成）

**独立数据来源：2,288个自然S0失败场景与其GT的配对加噪、完整去噪及最终重评分数据。现有`analysis/observation_v1`的配对差分、配对残差以及全部配对候选对照均属于路线二；其中的`global_class_residual`不是路线一。**

对同场景、同起始时刻与配对噪声下的成功／失败表征差分做SVD，检验差异是否集中在少数方向。保留最终PDMS差距和失败模式，不仅使用二值标签。然后按照路线一的方法对配对的成功GT/失败的样本做子空间+残差分析。由于路线一可能消耗计算量很大，路线二不应该被路线一阻塞或者必须等路线一完成。
